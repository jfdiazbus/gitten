git-hidden(1)
=============

NAME
----
git-hidden - Explicitly untrack files matching root .githidden rules

SYNOPSIS
--------
[verse]
'git hidden apply' [--dry-run]

DESCRIPTION
-----------
Remove tracked paths matching the repository-root `.githidden` from the
index, preserving all working files. The removals are staged for the next
commit. Previous commits are unchanged. The entire repository is considered,
even when invoked from a subdirectory.

All matching paths are validated before updating the index. Conflicted paths
and staged content that differs from both HEAD and the working file prevent
the operation. Running the command again after applying it has no effect.

OPTIONS
-------
--dry-run::
	List matching tracked paths after validation, without writing the index.

RULES
-----
`.githidden` uses the pattern syntax described in linkgit:gitignore[5]. Only
the repository-root file is read. Its exclusions are independent of ordinary
ignore rules: an exception in one cannot undo an exclusion in the other.

Matching untracked files are excluded from ordinary staging, status, and
file discovery using standard excludes. `git add -f` overrides exclusions.
Tracked files retain normal behavior until `git hidden apply` is run.

The rules file can itself be tracked. Stock Git does not interpret it;
these rules require gitten or this fork's Git executable.
